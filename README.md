# FlowINR demo data

Full-volume demonstration data for FlowINR, comprising 112 slices and
16 cardiac phases.

Download `FlowINR_demo_data.zip` from [Releases](https://github.com/yuhui-nanana/FlowINR-demo-data/releases)
and extract it into the FlowINR package directory.

The `demo_data/` folder contains:

- `kdata_ktGaussian50.npy`: undersampled multicoil MRI data.
- `coilmap.npy`: coil-sensitivity maps.
- `segmask.npy`: reference segmentation mask.

Checksums are provided in `SHA256SUMS.txt` and `data_manifest.json`.
